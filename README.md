## Features

- Bilingual site — English (default) and Spanish (`/es/` prefix), with a language switcher in the header
- Static-first: fully pre-rendered, served via nginx on Google Cloud Run
- Full-text search powered by [Pagefind](https://pagefind.app/) (runs at build time, no server needed)
- Dynamic Open Graph image generation per post (Satori + resvg)
- Light & dark mode
- RSS feed, sitemap, and SEO meta tags out of the box
- Syntax highlighting via Shiki (themes: `min-light` / `night-owl`) with custom transformers for file names, diff notation, and word highlights
- Table of contents and collapsible sections in Markdown posts
- Tag-based filtering, pagination, and archives

## Writing Blog Posts

Every post **must** exist in both languages. The file name must be identical so the language switcher can link between them.

```
src/data/blog/my-post.md        ← English  →  /posts/my-post
src/data/blog/es/my-post.md     ← Spanish  →  /es/posts/my-post
```

### Required frontmatter

```yaml
---
author: Tommy CardeLo
pubDatetime: 2026-01-01T10:00:00Z
title: My Post Title
featured: false
draft: false
tags:
  - tag-name
lang: en          # or "es" for the Spanish version
description: Short description.
---
```

Rules:
- `lang` is required on every post (both `en` and `es`)
- Both versions must share the same `pubDatetime`, `tags`, and `featured` flag
- A post with `draft: true` is excluded from all listings

## Running Locally

```bash
# Install dependencies
pnpm install

# Start the dev server at localhost:4321
pnpm run dev
```

The full production build (includes Pagefind indexing):

```bash
pnpm run build
pnpm run preview    # serve the built site locally
```

Or with Docker:

```bash
docker build -t tommycardelo-portfolio .
docker run -p 8080:8080 tommycardelo-portfolio
# open http://localhost:8080
```

## Commands Reference

| Command | Description |
|---|---|
| `pnpm run dev` | Dev server at `localhost:4321` |
| `pnpm run build` | Type-check → build → Pagefind index |
| `pnpm run preview` | Serve the built site locally |
| `pnpm run lint` | ESLint |
| `pnpm run format` | Prettier (write) |
| `pnpm run format:check` | Prettier (check only, used in CI) |
| `pnpm run sync` | Regenerate Astro TypeScript types |

## Deployment

Pushes to `main` trigger the GitHub Actions deploy workflow:

1. Build Docker image (Node 20 → nginx:alpine)
2. Push to Google Artifact Registry
3. Deploy new revision to Google Cloud Run (`us-central1`)

The container serves the pre-built static site via nginx on port `8080` (Cloud Run default).

## Configuration

Edit `src/config.ts` to update site metadata:

```typescript
export const SITE = {
  website: "https://tommycardelo.com/",
  author: "Tommy Cardenas Lopez",
  title: "Tommy CardeLo",
  desc: "Data Scientist & AI Engineer | Automation & ML systems",
  postPerIndex: 4,   // posts shown on the homepage
  postPerPage: 6,    // posts per listing page
  // ...
};
```

Social links and share links are managed in `src/constants.ts`.
